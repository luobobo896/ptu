## 🔧 技术实现

### Linux 实现

**文件**: `src/platform/linux.rs`

**实现方式**:
- 解析 `/proc/net/tcp` 和 `/proc/net/tcp6`
- 解析 `/proc/net/udp` 和 `/proc/net/udp6`
- 通过 `/proc/<pid>/fd` 查找 PID

**特点**:
- ✅ 原生实现，性能优异（50-200ms）
- ✅ 不依赖外部命令
- ✅ 代码行数: 398 行

### macOS 实现

**文件**: `src/platform/macos.rs`

**实现方式**:
- 使用 `lsof -iTCP` 获取 TCP 套接字
- 使用 `lsof -iUDP` 获取 UDP 套接字
- 解析 lsof 输出提取信息

**特点**:
- ✅ 可靠性高，使用系统自带工具
- ✅ 代码简洁易维护
- ✅ 性能满足日常需求（100-500ms）
- ✅ 代码行数: 372 行
- ✅ 6 个单元测试

## 🐛 Bug 修复记录

### macOS lsof 解析问题（已修复）

**问题**: 初次实现时，lsof 输出解析失败，返回 "No sockets found"

**根本原因**:
- lsof 输出的 NAME 字段包含空格（如 "TCP *:7000 (LISTEN)"）
- 使用 `split_whitespace()` 分割后，NAME 字段被拆分成多个部分
- 错误地只取最后一部分（如 "(LISTEN)"），导致解析失败

**修复方案**:
1. 修改解析逻辑，正确提取完整 NAME 字段（从索引 8 开始的所有部分）
2. 移除对 NAME 字段中 TCP/UDP 前缀的依赖
3. 根据调用上下文（get_tcp_sockets/get_udp_sockets）确定协议类型
4. 结合 TYPE 字段的 IPv4/IPv6 信息确定最终协议

**修改文件**: `src/platform/macos.rs`

**验证结果**:
- ✅ 列出监听端口: 27 个 socket
- ✅ 查询端口: 正常工作
- ✅ 查询进程: 正常工作
- ✅ 协议过滤: 正常工作（170 个 TCP socket）
- ✅ 所有功能: 200 个 socket 总计
