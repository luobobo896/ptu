## 当前限制（v0.1.0）

### 平台支持

#### ✅ Linux (完全支持)
- **状态**: 生产就绪
- **功能**:
  - ✅ 列出 TCP/UDP 套接字
  - ✅ 查询端口信息
  - ✅ 查询进程信息
  - ✅ 过滤和排序
  - ✅ JSON 输出

- **已知问题**:
  - ⚠️ 性能：在大量进程时可能较慢（遍历 /proc）
  - ⚠️ 某些容器环境可能无法访问 /proc

- **要求**:
  - Linux 内核 2.6+
  - /proc 文件系统可访问
  - 某些功能需要 root 权限

#### ✅ macOS (完全支持)
- **状态**: 生产就绪
- **实现方式**: 使用 `lsof` 命令获取网络信息
- **功能**:
  - ✅ 列出 TCP/UDP 套接字
  - ✅ 查询端口信息
  - ✅ 查询进程信息
  - ✅ 过滤和排序
  - ✅ JSON 输出
  - ✅ 支持 IPv4 和 IPv6

- **要求**:
  - macOS 10.12+ (Sierra 及以上)
  - `lsof` 命令可用（系统自带）
  - 某些功能可能需要 sudo 权限

- **性能**:
  - 使用外部命令（lsof）可能比原生实现稍慢
  - 对于日常使用，性能完全可接受

#### ❌ Windows (不支持)
- **状态**: 计划中
- **预计时间**: v0.3.0 或更晚

### 功能限制

#### 1. 性能

**Linux**:
- **问题**: `find_pid_by_inode()` 遍历所有进程的文件描述符
- **影响**: 在有 1000+ 进程的系统上可能需要 1-2 秒
- **计划优化**: v0.2.0 将添加缓存和索引

**macOS**:
- **问题**: 依赖外部命令 `lsof`
- **影响**: 比原生实现略慢，但对于日常使用完全足够
- **优化**: 已使用 `-n` 和 `-P` 选项避免 DNS 和服务名解析

#### 2. 权限

**通用**:
- **问题**: 需要适当权限才能查看所有进程信息
- **影响**: 某些套接字可能显示为 PID "-"
- **解决方案**:
  - Linux: 使用 `sudo ptu list`
  - macOS: 使用 `sudo ptu list`

#### 3. IPv6

- **问题**: IPv6 地址解析简化，可能不支持所有格式
- **影响**: 某些 IPv6 地址可能显示不正确
- **计划修复**: v0.1.1

#### 4. 实时监控

- **问题**: 不支持持续监控模式
- **影响**: 无法像 `watch ptu list` 那样实时刷新
- **计划添加**: v0.2.0

### 已知 Bug

#### Linux 平台
1. **轻微**: 某些容器的 /proc/net 不完整
   - **症状**: 某些套接字不显示
   - **变通**: 使用 `--tcp` 或 `--udp` 限制范围

2. **轻微**: find_pid_by_inode 可能失败
   - **症状**: PID 显示为 "-"
   - **原因**: 进程在扫描期间退出
   - **影响**: 轻微，仅影响部分套接字

#### macOS 平台
1. **轻微**: lsof 权限问题
   - **症状**: 某些系统套接字可能不显示
   - **解决方案**: 使用 `sudo ptu list`
   - **状态**: 正常行为，非 bug

### 使用建议

#### Linux 用户
```bash
# 推荐：列出所有监听端口
sudo ptu list --listen

# 推荐：查询特定端口
ptu get port 8080

# 推荐：JSON 输出用于脚本
ptu -j list | jq '.[] | select(.local_address.port == 8080)'
```

#### macOS 用户
```bash
# 推荐：列出所有监听端口
sudo ptu list --listen

# 推荐：查询特定端口
ptu get port 8080

# 推荐：查看进程信息
ptu get pid 1234

# 推荐：JSON 输出用于脚本
ptu -j list | jq '.[] | select(.local_address.port == 80)'
```
